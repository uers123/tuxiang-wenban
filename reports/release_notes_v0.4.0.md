# doc-textify v0.4.0 Release Notes

## 🎯 版本主题：真实文档验证 + 提取质量修复

v0.4.0 是 doc-textify 首次在真实学术论文（Robertson 1990 SBT/CPT，8 页双栏扫描件）上完成端到端验证的版本。基准评分从 60% 提升至 76%，并建立了可复现的 Benchmark 体系。

## ✨ 新特性

### 1. 双栏阅读顺序恢复
- 自动检测双栏版面（x 中心聚类 + 间隙分析）
- 按「左栏上→下，右栏上→下」恢复阅读顺序
- 单栏文档零影响（保守阈值：间隙 >15% 页宽 + 两侧 ≥3 块）

### 2. 扫描件公式检测
- 识别 OCR 碎片化公式（`AREA =a`、`g,`、`By =` 等）
- 公式检测移至版面分析流水线最前，避免被标题/页眉抢占
- 8 页论文公式识别：1 → 12 个公式块

### 3. 黑白图表结构识别
- PDF OCR 路径全面接入图表分析（此前仅图片路径）
- numpy 2.x 兼容修复（`ptp()` 移除）
- 无彩色图表的结构回退：长短线检测 → 区域聚类 → 轴标签/图注/结构条目
- 图 1/3/4/5 均成功输出 `chart_detected` 数据

### 4. 块分类精度大幅提升
- 修复 OCR 路径标题误判（69% → 2.5%）
- 新增测量值/公式守卫（含 `=` 或数字+单位 → 段落）
- 标题识别改为强信号：编号、CJK 短语、全词 Title Case、白名单

### 5. 评估框架增强
- `chart_detected` 结构条目单独计分（轴标签匹配）
- 混合计分：数据点 60% + 结构识别 40%
- Benchmark `--run` 标志修复（真实调用 doc-textify）

## 📦 基准结果

| 指标 | v0.3.1 | v0.4.0 |
|---|---|---|
| heading 误判率 | 69% | 2.5% |
| 公式块 | 1 | 12 |
| 双栏检测 | 无 | 6/8 页 |
| 图表识别 | 0 | 4 图 / 6 条目 |
| **基准评分** | **60%** | **76%** |

## 🔧 其他改进

- `models.Page` 新增 `_order_finalized`，双栏重排顺序不再被序列化覆盖
- 项目自包含：内置便携版 Tesseract（`tools/`），自动发现
- 新增 MIT License、PyPI 分类器、项目 URL

## 📁 文件变更

## ⚠️ 已知限制

- 图表数据点级提取（散点坐标）尚未实现，当前为结构级识别
- 公式输出为文本块，LaTeX 渲染输出待后续版本
- 中文双栏扫描件未验证（当前用例为英文）
